Updated for BGMI 4.7. Enter these in BGMI under Settings → Sensitivity. Since the 4.7 update, Sensitivity is the 4th tab (after Controls, Key Settings and Display).

How it's calculated

In BGMI a swipe turns the camera by how much of the screen width you cover. A wider screen needs a higher value for the same thumb movement, so Sens Lab uses your screen's real width to give the same comfortable swipe on any phone. Each scope is set to about 0.88 ÷ its zoom, so every scope feels consistent. Gyro works by tilt, so it barely depends on screen size.

Checked against the official BGMI 4.7 patch notes (released 18 Nov 2026): the update doesn't change sensitivity settings, scope zoom or aim assist, so these values still apply. Its only recoil change is about 10% less horizontal recoil on the ASM Abakan.

Open a guide to see the real layout, then copy it in BGMI: Settings → Controls (the first tab since update 4.7) → Customize, and tap Save.
